# WriteSpace

WriteSpace is a modern, fast, and minimal writing environment built with React and Vite. It provides a distraction-free space for writers, students, and professionals to focus on their words.

## Features

- Clean, minimal UI for focused writing
- Instant loading and live preview
- Responsive design for desktop and mobile
- Built with modern JavaScript and React

## Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- JavaScript (ES6+)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/your-username/writespace.git
   cd writespace
   ```

2. Install dependencies:

   ```
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```
npm run build
# or
yarn build
```

The production-ready files will be in the `dist` folder.
